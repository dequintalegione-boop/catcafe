# Сайт «Тюменское котокафе»
Откройте index.html двойным щелчком: сервер и сборка не нужны. Шрифты подгружаются из Google Fonts, без интернета работают запасные.
Фото: положите свои файлы в assets/ под именами photo-1.jpg … photo-4.jpg, они автоматически заменят иллюстрации в галерее.
Данные взяты с Яндекс Карт и Telegram-канала. Перед показом клиенту подтвердите цены, афишу и льготный тариф.

Фото котов: кладите в assets/ и пишите имя файла в столбце «Фото» таблицы.
Ссылка на канал в MAX уже подключена (переменная MAX_URL в script.js).
Коты и их истории хранятся только в Google Таблице: пока config.js пуст, разделы «Живут здесь» и «Нашли дом» скрыты.

Карта «Как добраться»: подключается скриптом Яндекс Конструктора в конце script.js (нужен интернет). Без загрузки карты показывается оформленная заглушка с кнопками маршрута.

Управление через Google Таблицу: загрузите catcafe-table.xlsx в Google Диск и откройте как Google Таблицу.
«Файл → Поделиться → Опубликовать в интернете», по очереди выберите лист «Коты» и «Афиша», формат CSV, скопируйте ссылки в config.js.

Афиша берётся только из листа «Афиша» таблицы. Если там нет строк с «Показывать» ≠ «Нет», на сайте показывается сообщение «Афиши нет» со ссылками на соцсети.

Диагностика: откройте сайт с добавкой ?debug в адресе (например, .../index.html?debug), внизу страницы появится отчёт о загрузке листов «Коты» и «Афиша».

Локальный режим: пока ссылки в config.js пустые, сайт показывает строки catsRows и eventsRows из config.js. Правьте их по образцу или вставьте ссылки Google, и они заработают как основной источник.
